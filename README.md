 ## 📢 NoticeBoard – Digital Notice Management System

One Platform. All Important Updates.

NoticeBoard is a centralized digital notice management system designed to make academic announcements easier to create, manage, and access.
The project aims to provide students and educational institutions with a simple platform where important notices and updates can be organized in one place.

## 🚀 Features

- **Dashboard:** View important notices in a centralized interface.
- **Notice Search:** Quickly find specific announcements.
- **Category Filtering:** Filter notices based on categories.
- **Department Filtering:** Find department-specific announcements.
- **Sorting:** Organize notices using available sorting options.
- **Saved Notices:** Keep important notices accessible.
- **Create Notice:** Add new announcements through a dedicated form.
- **Academic Reminders:** Access important academic reminders.
